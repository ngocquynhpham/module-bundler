# My Practice Project
This is my small project. I made a website to practice coding.

### What I Used
- Vite: I used Vite to build my project. Vite is a module bundler. It helps make my website fast.

- Navigo: I used Navigo for the pages. Navigo is a router. It helps me go to different pages like Home, Products, and Product Detail.

### What My Website Can Do
- It has a Home page with nice products.

- It has a Products page to see all products.

- You can click a product to see the Product Detail page.

- You can go back to the products list with a "Back" button.
